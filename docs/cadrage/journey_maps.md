# Journey Maps

## Journey Map 1 : Réunion à distance (Mode visioconférence)

| Étape         | Action utilisateur          | Attentes                              | Difficultés possibles     |
| ------------- | --------------------------- | ------------------------------------- | ------------------------- |
| Préparation   | Créer une réunion           | Démarrer rapidement une réunion       | Configuration complexe    |
| Captation     | Lancer la visioconférence   | Captation audio fiable                | Problèmes réseau          |
| Transcription | Enregistrement des échanges | Transcription fidèle                  | Erreurs de reconnaissance |
| Analyse       | Génération du résumé        | Obtenir un compte-rendu clair         | Résumé incomplet          |
| Consultation  | Consulter l'historique      | Retrouver les informations rapidement | Recherche difficile       |

## Journey Map 2 : Réunion en présentiel (Mode dictaphone)

| Étape         | Action utilisateur           | Attentes            | Difficultés possibles       |
| ------------- | ---------------------------- | ------------------- | --------------------------- |
| Préparation   | Ouvrir le mode dictaphone    | Démarrage rapide    | Autorisations micro         |
| Captation     | Enregistrer la réunion       | Bonne qualité audio | Bruit ambiant               |
| Transcription | Conversion audio → texte     | Texte exploitable   | Mauvaise qualité sonore     |
| Analyse       | Génération du compte-rendu   | Actions identifiées | Informations manquantes     |
| Consultation  | Accéder aux réunions passées | Historique organisé | Volume important de données |
