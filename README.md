# Scribe AI Assistant

Projet académique de pré-production et développement d'une application intelligente de gestion de réunions.

## Fonctionnalités

- Captation audio (dictaphone et visioconférence)
- Transcription automatique
- Attribution des locuteurs
- Classification du ton et des thèmes
- Génération de compte-rendu
- Gestion des actions
- Historique des réunions

## Technologies envisagées

- Python
- FastAPI
- Streamlit
- PostgreSQL
- Whisper
- PyAnnote
- OpenAI API

## Méthodologie

- Scrum
- GitFlow
- GitHub Projects
- CI/CD GitHub Actions
